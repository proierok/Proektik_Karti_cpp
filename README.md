# 📚 Флеш-карточки для изучения языков

Консольное приложение на C++ для создания и изучения карточек с иностранными словами. Поддерживает два типа карточек, поиск, сортировку и сохранение данных в файл.

## 🚀 Возможности

- Добавление обычных карточек (слово → перевод + уровень сложности)
- Добавление карточек с примером предложения
- Просмотр всех карточек
- Редактирование и удаление карточек по ID
- Поиск по вопросу или ответу
- Сортировка по алфавиту
- Автоматическое сохранение и загрузка из файла `data.txt`
- Поддержка русского языка в консоли

## 🛠️ Технологии

- **Язык:** C++17
- **Среда:** Visual Studio / любой компилятор с поддержкой C++17
- **ООП механизмы:**
  - Инкапсуляция, наследование, полиморфизм
  - Абстрактный базовый класс (`FlashcardBase`)
  - Шаблонный класс (`Repository<T>`)
  - Умные указатели (`std::shared_ptr`)
  - Стек на динамических узлах (`ActionStack`)
  - Работа с файлами (сохранение/загрузка)
  - Собственный класс исключения (`CardException`)
